# Kustomisasi Desktop Environment

Desktop Environment yang digunakan adalah GNOME
dengan kustomisasi visual untuk lingkungan akademik.

## Perubahan Visual
- Tema: Adwaita Dark
- Icon Pack: Papirus
- Font: Cantarell
- Wallpaper: Remon

## Alasan Pemilihan
- Tampilan bersih dan profesional
- Minim distraksi
- Mudah digunakan oleh mahasiswa baru
