# Manajemen Paket

Manajemen paket pada distro ini disesuaikan dengan kebutuhan
lingkungan laboratorium komputer dan pendidikan.

## Paket Ditambahkan
- Aplikasi produktivitas dan perkantoran
- Software edukasi dan sains
- Tool pendukung praktikum dan administrasi

## Paket Dihapus
- Game bawaan
- Aplikasi hiburan
- Aplikasi yang tidak relevan dengan kegiatan akademik

## Alasan Pemilihan Paket
- Open-source dan stabil
- Mendukung kegiatan belajar-mengajar
- Mudah dipelihara dan diperbarui
